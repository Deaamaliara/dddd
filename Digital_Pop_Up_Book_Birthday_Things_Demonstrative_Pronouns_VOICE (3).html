📖 Page 4 — The Easy Rule

Remember this!

☝️ ONE + NEAR = THIS

👉 ONE + FAR = THAT

☝️☝️ MANY + NEAR = THESE

👉👉 MANY + FAR = THOSE

Examples:
🎂 This is a cake.
🎁 That is a present.
🎈🎈 These are balloons.
🎉🎉 Those are party hats.
